1. Install dependencies

  • Ensure you have Python 3.11 or later installed.
  • Use a virtual environment to isolate dependencies.

2. Configure environment to connect to FedDB TestEmbed.

  • Replace APP_ID with your actual id.
  • Use a .env file for storage.

3. Create your config (or paste the generated one).

4. Create your model, which you register.

  • Ensure your model inherits from the BaseApp class.
  • Use your config for data validation.
  • Implement save and load methods for the model store.

5. Create your main.py
